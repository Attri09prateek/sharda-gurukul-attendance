📌 1-Minute Setup Guide (Google Sheet Apps Script):

  1. अपनी Google Sheet खोलें और मेन्यू में Extensions > Apps Script पर क्लिक करें।
  2. वहाँ google_apps_script.js का कोड पेस्ट करें (प्रोजेक्ट फ़ोल्डर में मौजूद है)।
  3. ऊपर Deploy > New deployment चुनें, Type में Web app सेलेक्ट करें।
  4. Who has access में Anyone चुनें और Deploy करके Web App URL कॉपी कर लें।
  5. नीचे दिए गए बॉक्स में URL पेस्ट करके Save & Sync दबाएं!
